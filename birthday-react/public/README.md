# Music & Photos Directory Guide

### 🎵 1. Music ("Tum Se Hi")
Place your audio file inside this folder with the name:
`birthday-react/public/music/tum-se-hi.mp3`

Supported formats: `.mp3`, `.m4a`, `.wav`, `.ogg`.
*Note: If no audio file is provided, a gentle, romantic synthesized piano ambient melody will play automatically without crashing.*

---

### 📸 2. Photos Gallery
Place your favorite memories & photos of your girlfriend inside:
`birthday-react/public/photos/`

Name them:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`

You can also customize the photo list, captions, dates, and titles directly in `src/config.js`!
